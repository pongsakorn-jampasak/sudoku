# Sudoku

เกม Sudoku แบบหน้าต่าง สร้างด้วย Python และ `tkinter` โดยไม่ต้องติดตั้งไลบรารีเพิ่ม

## วิธีเล่น

1. เปิดโปรแกรมด้วยคำสั่ง `python app.py`
2. กดปุ่มตัวเลข 1–9 ด้านล่าง แล้วคลิกช่องสีขาวที่ต้องการเติม
3. เมื่อกรอกครบทุกช่อง ให้กด **Done — ตรวจคำตอบ**
4. โปรแกรมจะตรวจเลขซ้ำในแต่ละแถว คอลัมน์ และกล่องย่อย 3×3

ช่องสีฟ้าเป็นตัวเลขตั้งต้นและแก้ไขไม่ได้ โจทย์ปัจจุบันเป็นระดับง่าย มีตัวเลขตั้งต้นมากขึ้น หากมีข้อผิดพลาด ช่องที่ต้องแก้จะเป็นสีแดง
