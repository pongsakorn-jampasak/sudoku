# Sudoku

เกม Sudoku แบบหน้าต่าง สร้างด้วย Python และ `tkinter` โดยไม่ต้องติดตั้งไลบรารีเพิ่ม

## วิธีเล่น

1. เปิดโปรแกรมด้วยคำสั่ง `python app.py`
2. เลือกระดับ **ง่าย** หรือ **ปานกลาง** ก่อนเริ่มเล่น
3. กดปุ่มตัวเลข 1–9 ด้านล่าง แล้วคลิกช่องสีขาวที่ต้องการเติม
4. เมื่อกรอกครบทุกช่อง ให้กด **Done — ตรวจคำตอบ**
5. โปรแกรมจะตรวจเลขซ้ำในแต่ละแถว คอลัมน์ และกล่องย่อย 3×3

ช่องสีฟ้าเป็นตัวเลขตั้งต้นและแก้ไขไม่ได้ ระดับง่ายมีช่องว่าง 30 ช่อง และระดับปานกลางมีช่องว่าง 45 ช่อง ทุกครั้งที่เริ่มเกมใหม่ ระบบจะสุ่มตัวเลขและตำแหน่งช่องว่างใหม่ หากมีข้อผิดพลาด ช่องที่ต้องแก้จะเป็นสีแดง
